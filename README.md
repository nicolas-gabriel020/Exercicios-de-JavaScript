# Exercícios de JavaScript

Repositório com exercícios de lógica de programação desenvolvidos em JavaScript, utilizando um pouco de HTML e CSS para interação.

O foco principal destes projetos é praticar:
- lógica de programação;
- manipulação do DOM;
- eventos;
- cálculos;
- condicionais;
- e estruturação do código em JavaScript.

A aparência visual não é o foco dos exercícios, mas sim o desenvolvimento da lógica e do raciocínio de programação.
